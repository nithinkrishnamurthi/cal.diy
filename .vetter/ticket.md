# Add a "Contact Support" link to the sidebar footer

Add a small "Contact Support" link to the bottom of the signed-in
app sidebar. The link should open https://cal.com/help in a new tab.

## Acceptance

- A link with text "Contact Support" is visible in the sidebar for
  signed-in users (on /event-types and any other main dashboard pages).
- The link points to https://cal.com/help and opens in a new tab
  (target=_blank, rel=noopener).
- No existing navigation items are moved or removed.
